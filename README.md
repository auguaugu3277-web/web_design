## Getting Started

1. Choose a template (web.html - web5.html)
2. Open in your browser
3. Customize content with your conference details
4. Update colors in CSS variables (`:root`)
5. Add your logo and images

## Technologies Used

- HTML5
- CSS3 (with CSS Grid & Flexbox)
- Vanilla JavaScript
- Bootstrap Icons
- Google Fonts

## Customization

All templates use CSS variables for easy color customization:

```css
:root {
  --primary-color: #yourcolor;
  --secondary-color: #yourcolor;
  /* ... more variables */
}
```
